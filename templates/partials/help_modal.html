Help & Tips

1. Upload a Dataset

  • Drag & drop or click to browse a .csv, .xlsx, or .xls file.
  • The first row should contain column headers.
  • The dataset schema is detected automatically after upload.
  • Both CSV and Excel datasets are supported.

2. Example Questions

  • show female patients older than 30
  • list all students
  • average salary by department
  • top 5 highest salary
  • lowest 10 prices
  • how many students from Dhaka
  • how many female employees
  • total sales by region
  • maximum age
  • minimum salary
  • age between 20 and 40
  • employees with salary greater than 50000
  • average temperature for June
  • houses with air conditioning
  • which year had the highest average rainfall

3. Supported Query Types

  • SELECT → Show or retrieve records
  • COUNT → Count records
  • AVG → Calculate an average
  • MAX → Find the maximum value
  • MIN → Find the minimum value
  • SUM → Calculate a total
  • GROUP BY → Group results by a column
  • ORDER BY → Sort results
  • LIMIT → Return the top N results
  • BETWEEN → Filter values within a range

4. Supported Keywords

  • average, avg → AVG()
  • total, sum → SUM()
  • count, how many, number of → COUNT()
  • maximum, max → MAX()
  • minimum, min → MIN()
  • highest → Sort descending
  • lowest → Sort ascending
  • top N → Sort descending and return N results
  • by → GROUP BY
  • greater than, more than, above → >
  • less than, below, under → <
  • between → BETWEEN
  • is, equals, equal to → =

5. Smart Matching

  • Column names can be matched using fuzzy matching.
  • Common domain synonyms are supported.
  • Column names with underscores can be matched naturally.
  • Month names such as June and January can be resolved.
  • Binary values such as yes/no can be detected from natural language.
  • Comma-separated numbers such as 5,000,000 are supported.

6. Accepted Question Starters

  • show, list, display, find, get, fetch, retrieve, return, select
  • what, which, who, where, when, how
  • please and kindly are optional.

7. Tips for Best Results

  1. Use simple English questions.
  2. Mention column names whenever possible.
  3. Use by <column> for grouped results.
  4. Use top N or lowest N for ranked results.
  5. Use greater than, less than, or between for filtering.
  6. Use natural values that exist in the uploaded dataset.
  7. Review the generated SQL before relying on the result.

8. Current Limitations

  • English language only.
  • Single-table queries only.
  • OR conditions are not supported.
  • IN filters are not supported.
  • Nested conditions such as (A OR B) AND C are not supported.
  • JOIN queries are not supported.
  • Natural language dates such as last month are not supported.

If a question is unclear or cannot be matched to the uploaded dataset, the system will display an error instead of generating unsafe or invalid SQL.
